# 📊 Trilha SQL – Minha jornada

Registro dos meus estudos e exercícios do curso **Trilha SQL** (SQL com PostgreSQL), usando um banco de e-commerce hospedado no Render e o DBeaver como cliente.

- **Conteúdo do curso:** [ckoliveiraa/TrilhaSQL](https://github.com/ckoliveiraa/TrilhaSQL) (material original e teoria, crédito ao autor)
- **Este repositório:** minhas resoluções dos exercícios das aulas e dos desafios finais

## 🛠️ Stack
PostgreSQL 18 · Render · DBeaver · psql
